# System Interference Visual Rules
### Mythic Forge Art Bible v2.0

**Governs:** allowed vs. forbidden visuals for Cipher-work, Fragment-Sync, and Breach phenomena, effect intensity scaling, and integration with the realism baseline. Per the Master System Prompt's System Rule 3, **no magic exists** — every visual in this file must read as system interference, data corruption, perception distortion, or emotional system instability. Never as magic.

---

## Allowed **[LOCKED]**

- Cipher-glow effects following the Color Language (`color-language.md`): cyan/icy-blue for fracture-anomaly phenomena.
- Visible strain and cost cues: caster fatigue, glow dimming or wavering under exertion, the pallor and unsteadiness of Burnout (World Bible Section 7).
- Fragment apparitions rendered as translucent, light-distorting, faintly glitching presences (`lighting-system.md`) rather than solid character models — visual static, scan-line distortion, and signal-dropout artifacts are appropriate; ghostly "magic" shimmer is not.
- Environmental Signal residue (faint, localized cyan-tinted haze, static, or glitch-texture) at sites of recent Cipher-work or a recent Breach.

## Forbidden **[LOCKED]**

- Any visual that reads as literal fantasy magic: glowing rune circles framed as spells, wands, spellbooks, medieval sword-and-sorcery iconography, or mystical rather than technological framing of any effect.
- Screen-filling, "video-game ability" particle-spam flashes.
- Any effect with no visible point of origin or system-logical cause.
- Any effect that reads as costless or infinite in scale.

## Intensity Scaling **[LOCKED]**

Effect scale must be proportionate to the Cipher-work tier or discipline level being used (World Bible Section 7):

| Tier/Level | Visual Scale |
|---|---|
| Novice Cipher-work | Small, humble, easily missed if not framed deliberately |
| Adept Cipher-work | Clearly visible, still contained and controlled-looking |
| Master Cipher-work | Commands the frame, but still shows visible strain on the user |
| Root-Tier / Root Artifact-bound | Screen-dominating scale permitted — and even here, cost must be visible in the same shot |

## Integration with Realism **[LOCKED]**

Cipher-glow and Fragment effects interact physically with their environment exactly as practical light does (`lighting-system.md`): they cast shadows, reflect off metal/glass surfaces, and obey falloff. Effects are never a flat overlay divorced from the shot's actual lighting setup.
