# Environment Design Rules
### Mythic Forge Art Bible v2.0

**Governs:** environment logic for the megacity's four layers, and environmental storytelling requirements.

---

## Core Requirement **[LOCKED]**

Every environment must visually answer "which layer of the city" within roughly two seconds of screen time, using palette, architecture, and silhouette alone — no on-screen text or dialogue exposition required.

## Layer Visual Logic **[LOCKED — World Bible Section 3]**

| Layer | Environment Visual Logic |
|---|---|
| Upper Grid | Sterile, minimal, symmetrical, white-dominant — order visible in the architecture itself; emotionally empty by design |
| Mid Zone | Regulated neon-adjacent signage (Authority-sanctioned, never chaotic), dense civilian housing, surveillance infrastructure visible but normalized |
| Lower Sector | Ward Station Seven's home layer — defensive, austere, minimal ornamentation, visible wear and improvised repair; Breach-adjacent zones show environmental distortion (Section "Environmental Storytelling Requirement" below) |
| Unknown Layer | Never fully rendered on-screen in detail — glimpsed only at the edges, defined by absence and static distortion rather than concrete geography |

## Root Artifact Sites **[LOCKED]**

Sites tied to the system's founding era (where Root Artifacts are found) use a consistent visual language distinct from any single layer's ordinary architecture: grander scale, more precise geometry, and a material perfection that reads as structurally advanced beyond what current-era Ward Division technology could produce (`materials-and-textures.md`, "Root Artifact Exception"). This is a subtle, purely visual "something more advanced was here" cue — it must never be explained on-screen; it is meant to be felt.

## Environmental Storytelling Requirement **[LOCKED]**

Signs of ongoing Breach activity — corrupted-signal ground distortion, memorial markers for past incidents, static-heavy transition zones near Lower Sector boundaries — should appear as background texture detail even when not plot-relevant in a given scene. History is present whether or not a character comments on it; the world continues existing off-page (World Bible Section 15, Rule 6).
