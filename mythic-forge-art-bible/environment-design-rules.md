# Environment Design Rules
### Mythic Forge Art Bible v1.0

**Governs:** worldbuilding environment logic — ruins, villages, temples, nature — and environmental storytelling requirements.

---

## Core Requirement **[LOCKED]**

Every environment must visually answer "which Realm, which Aspect" within roughly two seconds of screen time, using palette, architecture, and silhouette alone — no on-screen text or dialogue exposition required. This is the environmental equivalent of the Character Design Standards' silhouette test (Bible Section 8).

## Ruins **[LOCKED]**

Pre-Fracture (Elysian) ruins use one **consistent architectural language across all seven Realms**, distinct from each Realm's own living architecture: grand scale, symmetrical composition, Old Elysian script motifs (Bible Section 31), and a weathering pattern that reads as structurally advanced beyond what local material and craft could explain. This is a subtle, purely visual "something greater was here" cue — it must never be explained on-screen; it is meant to be felt (Bible Section 55, "world rewards curiosity").

## Settlements **[LIVING SECTION]**

Scale and density reflect each Kingdom's governance style (Bible Sections 7, 17):

| Realm | Settlement Visual Logic |
|---|---|
| Emberfall | Vertical, dense, built into calderas — visible hierarchy in elevation |
| The Tidewrought | Stilted, modular, built for impermanence and tidal change |
| The Ironroot Expanse | Carved directly into stone, permanent, low external silhouette |
| The Windmere Reaches | Modular, fleet-based, no fixed settlement reads as "temporary by design," not unfinished |
| The Duskmarch | Fortress-monastery logic — defensive, austere, minimal ornamentation |
| The Solvane Dominion | Terraced, symmetrical, marble — order visible in the skyline itself |
| The Verdant Wilds | Grown, not built — no hard geometric edges, structures integrated into living plant matter |

## Temples and Sacred Sites **[LIVING SECTION]**

Choir Faith architecture encodes which Aurothi is being venerated, matching that Aurothi's domain (Bible Section 3): flame-spiral verticality for Ignareth's Order, wave-motif curvature for Maelith's, and so on through all seven — see `../bible/Mythic_Bible_v3.0.md` Section 54 for the associated iconographic motifs, which this document visualizes but does not redefine.

## Environmental Storytelling Requirement **[LOCKED]**

Signs of the Fracture's ongoing effects — Rift-scarred ground, Ashfall-era memorial markers, Scarland transition zones (Bible Section 6) — should appear as background texture detail in relevant Realms even when not plot-relevant in a given scene. History is present whether or not a character comments on it, matching the world rule that "the world continues existing off-page" (Bible Section 55, Rule 6).
