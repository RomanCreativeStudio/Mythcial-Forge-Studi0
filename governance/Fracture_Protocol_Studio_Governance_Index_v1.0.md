## 2. Authority Flow

| Question | Answer |
|---|---|
| Who approves a canon change? | Founder only, via a Founder Override Command (Master Prompt §13) |
| Who approves a Locked process-document change? | Founder |
| Who approves a Living process-document change? | Creative Director (currently = Founder) |
| Who approves routine production sign-off? | Per Production Bible §11 — no Override Command needed |
| What can an AI approve unilaterally? | Housekeeping only (broken links, stale terms, version syncs) — never canon, never a Locked section, never a cross-document jurisdiction call |
