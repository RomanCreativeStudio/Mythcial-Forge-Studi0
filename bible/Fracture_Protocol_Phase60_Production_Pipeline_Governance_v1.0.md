## Purpose

Establish permanent governance for every production asset. This is not a story document. This is not an asset document. This is a production governance document.

---

## Production Authority Hierarchy

1. Master System Prompt
2. Locked Canon
3. Production Bible
4. Approved Screenplays
5. Production Pipeline
6. Storyboards
7. Concept Art
8. Character Assets
9. Environment Assets
10. Animation Assets
11. Audio Assets
12. Final Edit
13. Master Release

Higher authority always overrides lower authority.

---

## Asset Creation Rule

Every asset must originate from: **Approved Screenplays. Only.**

Never from:
- Memory
- Older drafts
- Production packages
- Character Bible
- World Bible

Those explain intent. The screenplay governs production.

---

## Asset Approval Rule

Every production asset requires:
- Asset Review
- Alignment Audit
- Founder Approval
- Version Number
- Asset Registry Entry
- Repository Commit
- Repository Push

No exception.

---

## Asset Revision Rule

Any asset modification requires:
- Reason
- Affected screenplay
- Affected scene
- Regression review
- Founder Approval

No silent edits.

---

## Production Conflict Rule

If production discovers:
- Asset contradiction
- Screenplay conflict
- Visual inconsistency
- Canon inconsistency
- Repository inconsistency

Production stops immediately.

---

## Asset Registry Rule

Every approved asset must immediately be added to the Asset Registry. No approved asset may exist outside the registry.

---

## Versioning Rule

Every production asset receives:
- Unique ID
- Version Number
- Creation Date
- Approval Date
- Dependencies
- Usage Episodes
- Production Status

---

## Applicability

This document applies to every production asset created from this point forward, across all remaining phases of production (Phase 6A and beyond), for all 36 Approved Phase 5B screenplays.
