## Lighting Canon — Governing Rule (Step 3)

Per the directive's own instruction, every conflicting lighting description found across the environment batch is evaluated against exactly two possible determinations:

**A. Intentional difference** — justified by a specific, identifiable story cause (time of day, story mood, power failure, a specific narrative beat such as defiance-under-pressure). If found, the rule governing the difference is documented explicitly, so future production knows which register applies when.

**B. Genuine contradiction** — no identifiable story cause justifies the difference; the two descriptions simply conflict. If found, this is flagged for Founder decision, never silently resolved by picking one description over the other.

This rule is applied per-environment in each package's own Phase 6C.5 Reconciliation Section, below (see in particular Environment 6, Night Haven, which carries the one confirmed lighting conflict from Phase 6C).

## Environment Identity — Required 13-Field Structure (Step 4)

Every environment's Reconciliation Section includes: Permanent Identity · Purpose · Narrative Function · Visual Function · Production Function · Reuse Strategy · Asset Dependencies · Animation Complexity · Lighting Rules · Material Rules · Color Rules · Camera Rules · Environmental Storytelling Rules. All fields are derived exclusively from Locked Canon and the sources listed above; a field with no Locked source is flagged as missing, never invented — the same discipline already established throughout Phase 6C.

---

## Production Readiness Standard (Step 6)

Three states only: **READY** (no open blocker; concept art may proceed), **IN PROGRESS** (minor open items exist but do not block initial production work), **BLOCKED** (a specific, named blocker prevents production from proceeding). Every BLOCKED determination documents: the exact blocker, its severity, the specific Founder decision required to resolve it, and a recommended resolution — offered as a recommendation for the Founder's own decision, never self-authorized.
