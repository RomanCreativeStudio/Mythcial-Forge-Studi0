## Step 1 — Confirmation: Is the Locked Base Prompt Portrait-Oriented?

**Confirmed yes, not newly discovered here — restated from the FPP-CHAR-002 External Production Package's own Step 2 finding.** The Kael Base Prompt Template's own text — *"high detail face, shallow depth of field"* — is bust/portrait framing language. This is not a theoretical concern: all three prior generation attempts using this exact, unmodified prompt (the Approved FPP-CHAR-001 still, and both rejected first/second-generation attempts) produced bust/shoulders crops, never a full body. This precedent is direct, empirical evidence, not inference.

---

## Step 2 — Story Canon or Production Standard?

**Production Standard.** Camera framing, body coverage, pose neutrality, and orthographic intent are execution-level production concerns — they determine how a shot is composed, not who the character is, what he wears, how he is lit, what he feels, or how the image is rendered. None of these touch Story Canon, Character Canon, or Visual Design in the sense those terms have been used throughout this production (fictional-world facts, character identity/costume/color, established narrative content). This is the same classification already applied to the Character Turnaround Production Standard's own view-count decision (Front/Side/Back) — a production specification, not a canon fact.

---

## Step 3 — Turnaround View Modifier Standard

**Appended separately from the Locked Base Prompt Template, never merged into it or into `prompt-library.md`.** Three modifiers, one per Character Turnaround Production Standard view, reusable across every future Turnaround asset for any of the four active principal characters — nothing character-specific is encoded in any of them:

| View | Modifier |
|---|---|
| Front | `full-body front view, standing neutral reference pose, facing camera directly, orthographic character reference framing, feet visible, no dramatic angle or foreshortening` |
| Side | `full-body side profile view, standing neutral reference pose, facing perpendicular to camera, orthographic character reference framing, feet visible, no dramatic angle or foreshortening` |
| Back | `full-body back view, standing neutral reference pose, facing away from camera, orthographic character reference framing, feet visible, no dramatic angle or foreshortening` |

**Application rule:** for each Turnaround view, the Final Production Prompt is `[Locked Base Prompt Template] + [Locked Emotion Modifier] + [View Modifier, above]`, appended in that order, exactly as Emotion Modifiers are already appended to the Base Template today — the View Modifier is never used standalone and never substitutes for the Base Template or Emotion Modifier.
