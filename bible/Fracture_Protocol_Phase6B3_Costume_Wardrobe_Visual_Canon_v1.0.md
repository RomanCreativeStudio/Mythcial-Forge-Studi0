# THE FRACTURE PROTOCOL — PHASE 6B.3: COSTUME & WARDROBE VISUAL CANON

**Classification:** Internal — New Locked Production Canon Document (**LOCKED CANON, effective immediately**)
**Status:** Compiled 2026-07-15 per "Founder Directive — Phase 6B.3 Costume & Wardrobe Visual Canon (v1.0)." This document resolves the one remaining shared production gap identified across every Phase 6B character package and confirmed by Phase 6B.2's own Final Certification: no Locked Costume Authority exists for any principal character. This is a Production Canon document — it is not story canon, does not rewrite screenplay content, and defines only visual production authority for clothing and wearable equipment.
**Absolute authority:** subordinate to Master System Prompt → Locked Canon (Character Bible, Faction Bible, World Bible, Phase 2 series) → Production Bible → Approved Screenplays (Phase 5B, Locked under Phase 5B.5) → Phase 6.0 → Phase 6A → Phase 6A.5 → Phase 6B Character Production Packages → Phase 6B.1 Visual Manifestation Canon → **Phase 6B.2 Human Character Visual Canon**. This document sits beneath Phase 6B.2 and Phase 6B.1 and above the Character Production Packages, per the directive's own explicit placement instruction — it extends, and must never contradict, either visual canon document.

## 1. Costume Authority

Costume exists to reinforce identity, profession, culture, status, history, personality, and story function. Costume may never exist purely because it "looks cool" — every element in this document is justified against a specific Locked source, cited inline. Where no Locked source justifies a specific decorative choice, that field is explicitly flagged as an open concept-art item rather than invented.

**Source Authority (cited throughout, never from memory):** Character Bible, Faction Bible, World Bible, Approved Screenplays, Phase 6B.0 Character Production Packages, Phase 6B.2 Human Character Visual Canon, Phase 6B.1 Guardian Visual Manifestation Canon.

**New direct screenplay evidence found this pass, not previously cited in any Phase 6B document:** Episode 1, Scene 2 (lines 227–244) — Mira to Kael: *"You're late for someone who was already here an hour ago in a different uniform."* This is the first and only direct textual confirmation that Kael wears more than one distinct outfit across a single day, and it directly grounds the Primary/Secondary Outfit distinction below rather than requiring it to be inferred from role alone. The same scene stages Mira "mid-task, hands occupied, not posed," reconfirming her hands-focused work-wear identity already established in Phase 6B.2.

## 2. Kael Aurelian Veyr — Costume Canon

**Grounding:** Ward Division Cadet (World Bible §6, rank ladder Cadet → Ward → Senior Ward → Division Director); Light 98th-affiliated; combat protagonist across all 36 episodes; practical, image-unconcerned personality (Phase 6B.2 Visual Philosophy); muted-practical color palette with cyan reserved exclusively to his eyes (Phase 6B.2 Color Philosophy); direct confirmation of multiple distinct outfits (Episode 1, above).

### Outfits

- **Primary Outfit.** Ward Division Cadet field uniform — practical, functional, muted neutral tones (grays, worn blues, earth tones). This is the uniform implied as his default by Episode 1's "different uniform" line — the one he is *not* wearing in that private scene. No specific rank-marker or insignia design is Locked anywhere; the rank ladder's existence (World Bible §6) implies some rank-marking convention must exist structurally, but its exact visual form is an open concept-art item, not invented here.
- **Secondary Outfit.** Off-duty/personal wear — directly confirmed by Episode 1's dialogue evidence. Simpler, less structured than the Primary uniform, consistent with his Phase 6B.2 Posture rule ("opens in rare private/vulnerable moments"). Functions as his civilian outfit as well (see below).
- **Formal Outfit.** A Ward Division dress variant for Division-level ceremonial occasions. Grounded in the rank hierarchy's structural existence (World Bible §6) and the Locked Framing Rule reserving centered symmetry for "ceremonial or system-significant moments" (`camera-language.md`) — inferred from structural/organizational Locked facts, not from a confirmed specific screenplay scene. Flagged as an open item pending a future screenplay or Founder confirmation of an actual ceremonial occasion.
- **Mission Outfit.** Combat/field-operations gear — grounded directly in his Locked Combat Ready pose requirement (Character Production Package, Section 6) and his Light 98th-affiliated action content across the full 36-episode arc.
- **Civilian Outfit.** Not a distinct fourth register — folded into Secondary Outfit above. Kael has no confirmed non-military civilian identity independent of his Ward Division life (unlike Mira); inventing a separate civilian wardrobe would not be justified by any Locked source.

## 5. The Guardian — Costume Canon

**Grounding:** Phase 6B.1 Visual Manifestation Canon established the Guardian's visual manifestation as a deliberately ordinary, unremarkable humanoid presence — no glow, no VFX, no lighting distinction from human characters, no assigned signature color, no religious/mythological/mechanical iconography (Phase 6B.1, Symbolic Design Language). **Costume must extend, not contradict, that design principle.**

**A necessary reasoning note, stated explicitly:** Phase 6B.1's own Costume Breakdown (in the Guardian's Character Production Package) was recorded as "Not Applicable — no confirmed physical embodiment." That finding predates Phase 6B.1 itself, which subsequently *did* establish a confirmed humanoid form. An ordinary humanoid presence that is never clothed would itself be a distinctive, memorable visual choice — directly contradicting the "ordinary, unremarkable" mandate Phase 6B.1 exists to protect. Costume is therefore now appropriate and necessary, on the condition that it is designed to be as close to visually invisible as clothing can be — the Guardian's costume must never communicate identity, profession, culture, status, history, or personality, in direct tension with this document's own Section 1 principle for the three human characters. This tension is resolved, not ignored: for the Guardian specifically, the correct fulfillment of "costume reinforces identity" is a costume that reinforces the *absence* of a legible identity, since that absence is itself the Locked characterization (Phase 6B.1, Mystery Protection Rule).

### Outfits

- **Primary Outfit.** Deliberately plain, unmarked, civilian-adjacent clothing — no faction affiliation, no insignia, no era-specific or culturally-specific styling. Chosen specifically to prevent the clothing itself from functioning as an implicit answer to the origin mystery.
- **Secondary / Formal / Mission / Civilian Outfits.** **Explicitly collapsed into the single Primary register — not four undefined gaps.** Unlike the three human characters, the Guardian does not vary its attire by context. Introducing outfit variation would itself be a distinctive, memorable design choice, directly contradicting Phase 6B.1's Visual Consistency Rule ("every rule... must render identically across all episodes"). One unchanging, deliberately forgettable outfit is the correct design.

### Production Attributes

| Field | Definition |
|---|---|

## 8. Production Rule — Shared Assets & Reuse Opportunities

Per the directive's explicit instruction, this section identifies shared production opportunities only — **no asset is created here**, only production authority.
