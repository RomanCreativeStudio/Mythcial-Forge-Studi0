## Canon Implementation Rule

Every screenplay must faithfully translate existing approved canon into cinematic form.

**A screenplay may:** determine scene flow; write dialogue; describe action; establish pacing; define transitions; specify camera language; specify animation direction; specify sound direction; specify performance direction; specify editing rhythm.

**A screenplay may not:** create new lore; invent new history; invent new abilities; invent new technology; invent new factions; invent new organizations; invent new political structures; invent new relationships; invent new motivations; invent new world mechanics; invent new character arcs; move approved story beats; relocate canon milestones; resolve protected mysteries early; contradict any Locked authority.

---

## Missing Canon Rule

If screenplay development requires information not explicitly contained within Locked Canon, the screenplay must **immediately stop.**

Do not infer. Do not extrapolate. Do not "fill in" missing lore. Do not invent details for convenience.

Instead:
1. Identify the missing information.
2. Cite the point in the screenplay where it is required.
3. Explain why the existing Locked Canon is insufficient.
4. Mark the issue as **Founder Review Required.**

Only a Founder Directive may authorize additional canon. This rule is the Phase 5-specific application of the same discipline already exercised throughout Phase 4A.2, Phase 4A.3, and every Phase 4B episode package's own "Missing Locked Authority" stop condition — carried forward unchanged, not newly invented here.

---

## Dialogue Rule

Dialogue exists to express approved characterization. Dialogue may deepen emotion, pacing, and personality. **Dialogue may never change a character's established beliefs, motivations, or development. No dialogue may introduce new canon.**

---

## Visual Rule

Visual storytelling may expand presentation. It may never expand lore. Environmental detail, cinematography, staging, and symbolism are encouraged only when fully consistent with existing canon (Art Bible: `mythic-forge-art-bible/`).

---

## Performance Rule

Actors, storyboard artists, directors, animators, composers, and editors may interpret emotional performance. **They may not reinterpret canon.**

---

## Screenplay Verification (required before any screenplay receives Founder Approval)

- Every scene traces to approved canon.
- Every dialogue exchange reflects established characterization.
- Every action matches approved story progression.
- Every emotional beat aligns with the Character Bible.
- Every visual element aligns with the Art Bible.
- No new canon has been introduced.
- No protected mystery has been altered.
- No milestone has been moved.
- No unsupported implication creates new lore.

---

## Founder Override

If uncertainty exists, preserve existing canon. Never resolve uncertainty by creating new canon. Founder authorization is required before any canonical expansion.

---

## Permanent Production Rule

From this point forward: **screenplays implement canon. Only Founder Directives create canon.** This rule remains in force for all future screenplay development unless explicitly superseded by a later Founder Directive.
