**Flagged, not resolved: a genuine framing gap between the Locked prompt and this deliverable's structural requirement.** The Base Prompt Template's own language — "high detail face, shallow depth of field" — is a bust/portrait framing specification. Every prior generation using this exact, unmodified prompt (the Approved FPP-CHAR-001 still, and both rejected first/second-generation attempts) produced a bust/shoulders crop, never a full-body image. A true Front View orthographic Turnaround requires the character's full body — including the newly-Locked Legwear and Boots — to be visible. **No Locked source anywhere (`prompt-library.md` or otherwise) defines a "full body" or "view/angle" modifier of any kind**, unlike the Emotion Modifiers, which are an explicit, enumerated Locked table. Using the prompt exactly as assembled above carries a demonstrated, precedented risk of again producing a bust crop rather than the required full-body Front View. This is disclosed here rather than resolved by inventing framing language on this package's own authority — resolution requires either a Founder Decision authorizing specific framing language for Turnaround prompts, or a new Locked View Modifier addition to `prompt-library.md`, parallel to the existing Emotion Modifiers table. Neither is decided here.
