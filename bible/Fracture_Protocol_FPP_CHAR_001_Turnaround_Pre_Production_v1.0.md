## Step 1 — Deliverable Audit: Turnaround View Requirements

A full search of every Locked source citing "Turnaround" (Phase 6A.5's own Character Standards, the Art Bible Concept Art Standard Expansion, every prior FPP-CHAR-001 record in this session) was performed. **Finding, stated plainly: no Locked source anywhere in this repository specifies which views, or how many, a Turnaround must contain.** Every citation uses "Turnaround" only as a category name, exactly as it appears in Phase 6A.5's own list ("Every character asset must include: Turnaround, Expressions, Poses, Scale Reference, Color Reference, Material Reference, Lighting Reference, Animation Reference") — never expanded into an angle list, view count, or format definition anywhere in the Art Bible, Production OS, Studio OS, or Phase 6A.5 itself.

Per this directive's own explicit instruction ("Do not invent additional views"), **no view list is reported here as required** — inventing the industry-standard front/three-quarter/side/back convention would itself be exactly the invention this directive forbids, however common that convention is outside this production. This is reported as the audit's actual finding, not worked around.

**This is the single largest open item blocking Turnaround pre-production and is carried into Step 3 as a Founder-decision item.**

## Step 2 — Canon Extraction: Locked Elements That Must Remain Identical Across Every View

Extracted only from already-documented, cited Locked Canon — nothing inferred:

**Physical identity** (`Fracture_Protocol_Phase6B2_Human_Character_Visual_Canon_v1.0.md` §3):
- Age 19 (Locked, item 6), within Master System Prompt Section 4's 17–20 range.
- Height range 178–185 cm (item 4).
- Lean-athletic, Cadet-trained build; athletic-functional proportions, not stylized hypermasculine bulk (items 3, 5).
- Open, direct, sincere facial features; youthful but visibly carrying strain and maturity (item 6).
- Dark, short, practical hair — no vanity styling (item 8).
- Practical field-Cadet skin texture, light-to-medium tone, plausible minor scarring/weathering; never physically flawless or unweathered (items 9, 20).
- Hands capable and marked by training — calluses and small scars (item 10).

**Eyes / eye-glow** (Master System Prompt Section 4 `[LOCKED]`; `mythic-forge-art-bible/color-language.md`):
- Icy blue-cyan baseline, intensifying with Signal-Sensitivity.
- Governed by the Locked Emotion Modifier table (Calm/Conflict/Activation/Breakdown) — the eye-glow is his singular, primary, dynamic diagnostic cyan signal.

**Costume — Primary Outfit** (Master System Prompt Section 4 `[LOCKED]`; `Fracture_Protocol_Phase6B3_Costume_Wardrobe_Visual_Canon_v1.0.md` §2, v2.0):
- Futuristic dark techwear; black/charcoal dominant palette; high collar or hooded jacket; lightweight tactical elements; fingerless or tech-integrated gloves (Master System Prompt Section 4, "core design — never change").
- Subtle cyan accents on the outfit, static and structural, always secondary to and never rivaling the eye-glow's own prominence (Phase 6B.2 Amendment v1.3).
- Functional, close-fitting gloves; simple, non-ornamental load-bearing belt; practical, high-function, field-weather-appropriate collar (no decorative treatment); practical, non-restrictive sleeve construction.
- Muted neutrals dominate the palette; matte, practical textures throughout — no glossy or attention-drawing surface treatment.

**Rendering** (`mythic-forge-art-bible/visual-development-guide.md`; `forbidden-elements.md`):
- Semi-realistic anime cinematic hybrid: detailed, cinematically lit, high-detail facial focus — identical register required on every view, no exceptions.
- Full Forbidden Elements blacklist applies identically to every view: no fantasy-magic signifiers, no flat cel-shading/speed lines/chibi breaks, no copied/reskinned IP, no costless system effects, no real-world brand/text/signage intrusions, no gratuitous content.

**Do Not Do** (Phase 6B2 item 20, as amended):
- Never render the eye-glow at Activation intensity unless Signal-Sensitivity is active in-scene.
- Never give him idealized, hypermasculine proportions.
- Never let the outfit's cyan accents rival, echo, or approach the eye-glow's prominence.
- Never render him as physically flawless or unweathered.

## Step 4 — Prompt Strategy

**Multiple prompts are required — one per view, not one combined multi-view prompt.** Justified on dependency and consistency grounds only:

- **Dependency:** the Locked Kael Base Prompt Template (`prompt-library.md`) is defined as producing "a consistent, on-model **still**" — a single-image deliverable. No Locked template or precedent describes a multi-panel or multi-angle sheet as a valid single-generation output. Each view is therefore dependent on its own individual application of the Base Prompt Template plus its own angle-specific qualifier (a qualifier the Locked template does not itself contain, since it is angle-agnostic).
- **Consistency:** the Step 2 list of elements that must remain identical across every view can only be verified per-view — exactly as the already-Approved Primary Outfit still was individually reviewed under Stage 1 Creative Validation and Stage 2 Technical Certification. A single generation attempting multiple angles at once could not be checked against that list with the same rigor, and this production's own direct experience (the first- and second-generation Primary Outfit attempts introducing unauthorized invented content) demonstrates that generation drift is a real, not theoretical, risk requiring independent per-output verification.

**The exact number of prompts cannot be finalized until Step 3, Item 1 (the view count) is Founder-decided** — the strategy (one prompt per view, each independently generated and independently validated) is determined now; the count is a direct function of that still-open decision.
