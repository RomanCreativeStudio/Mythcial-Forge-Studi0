## 3. Production Checklist — For the External Artist or AI System

**Use only the Locked Production Prompt above, verbatim.** Do not add, remove, or rephrase any word in it.

**In addition to the prompt text, the resulting image must independently conform to the following already-Locked specifications, none of which are encoded in the prompt's own wording and must therefore be honored by the artist/system directly, not assumed from the prompt alone:**

- [ ] **Silhouette and proportions** (Phase 6B.2 §3, items 3–5): lean-athletic, Cadet-trained build; height approximately 178–185 cm; athletic-functional proportions, not stylized hypermasculine bulk.
- [ ] **Hair** (Phase 6B.2 §3, item 8): dark, short, practical — no vanity styling.
- [ ] **Skin** (Phase 6B.2 §3, item 9): practical field-Cadet texture, light-to-medium tone, plausible minor scarring/weathering — not pristine "hero" rendering.
- [ ] **Facial structure** (Phase 6B.2 §3, item 6): open, direct, sincere features; youthful (age 19) but visibly carrying strain and maturity.
- [ ] **Costume — Primary Outfit** (Phase 6B.3 §2): muted neutrals dominate; functional, close-fitting gloves; simple load-bearing belt; practical high-function collar; matte, practical textures throughout (no glossy surfaces); the outfit's subtle cyan accents (per Master System Prompt Section 4, restored by Phase 6B.2 Amendment v1.3) remain secondary and static — they must never rival or approach the eye-glow's own visual prominence.
- [ ] **Eye-glow primacy** (Phase 6B.2 §3, item 15; color-language.md): the eye-glow is Kael's singular, primary, dynamic diagnostic cyan signal — it must read as unmistakably the strongest cyan element in the image, with the outfit's accents visibly secondary.
- [ ] **Rendering register** (`visual-development-guide.md`; `forbidden-elements.md` item 2): semi-realistic anime cinematic hybrid — detailed, cinematically lit, high-detail facial focus. Never flat cel-shading, speed lines, chibi proportion breaks, or single-tone eye highlights.
- [ ] **Forbidden Elements blacklist** (`forbidden-elements.md`, full list — automatic QA failure on any violation): no fantasy-magic signifiers (rune circles, wands, spellbooks, sword-and-sorcery iconography); no copied/reskinned existing published IP; no costless or infinite-looking system/particle effects; no modern real-world brand logos or real-world alphabet signage; no gratuitous or exploitative violence.
- [ ] **Output specifications** (Section 2, above): 4000 × 4000 px, sRGB, delivered as a finished raster master plus a native-resolution PNG export.

**Not included in this checklist, and not to be invented by the artist/system:** exact hex/color values, exact hair shade, exact skin tone, exact height within the stated range, rank-marker design, and any costume element not already named above — all remain genuinely open per Phase 6B.2/6B.3's own "Production Notes" flags. If the external process requires a specific value for any of these to proceed, that value must be returned as a flag alongside the asset, not silently decided.
