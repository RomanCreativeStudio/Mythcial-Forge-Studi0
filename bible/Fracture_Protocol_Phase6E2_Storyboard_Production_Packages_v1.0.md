# THE FRACTURE PROTOCOL — PHASE 6E.2: STORYBOARD PRODUCTION PACKAGES

**Classification:** Internal — Production Document (**Approved**)
**Status:** Compiled 2026-07-15 per "Founder Directive — Phase 6E.2 (v1.0)." Continues from Locked Phase 6E.1. Builds one Production Package for each of the 16 storyboard sequence groups identified there (FPP-SB-001 through FPP-SB-016). No storyboard panel, shot, or artwork is created here — every package below is a governance/reference document defining how storyboard work on that sequence group must proceed, not the storyboard work itself, per Phase 6E.0's and this directive's own explicit scope limit.
**Absolute authority:** subordinate to Master System Prompt → Locked Canon → Approved Screenplays → Art Bible → Phase 6C Environment Production Canon and its full reconciliation lineage → Phase 6E.0 Storyboard Production Governance → Phase 6E.1 Storyboard Asset Inventory → **this document**.
**Research method:** each package's fields are drawn directly from its governing Environment Production Package's own Camera Language, Lighting Rules, Composition, and Blocking findings (already Approved through Phase 6C and its reconciliation lineage), cross-checked against the specific screenplay scenes read directly during Phase 6E.1's own inventory pass and, where cited below, re-verified again for this package build. Where scene-level detail was not independently re-read for a specific episode within a sequence group, this is disclosed rather than presented as verified.

## FPP-SB-001 — Ward Station Seven Sequences

- **Authority:** FPP-ENV-001 (Ward Station Seven Environment Production Package); direct scene text from Episodes 1, 2, 3, 7, 8, 9, 11, 12, 13, 14, 15, 22, 23, 24, 25, each read during Phase 6C.5/6C.8/6E.1 research.
- **Governing Screenplay Scenes:** 49 scenes across Episodes 1, 2, 3, 7, 8, 9, 11, 12, 13, 14, 15, 22, 23, 24, 25 (full scene-by-scene breakdown in Phase 6E.1, Report 1).
- **Governing Environment:** FPP-ENV-001, READY.
- **Camera Language:** **No single confirmed general template exists** — this is the widest-varying sequence group in the production. Confirmed scene-specific citations directly re-verified: Episode 1's progression ("wide, unhurried framing → handheld-adjacent, populated-space framing → the episode's first close-up coverage → held, quiet framing → sustained hold on Kael's reaction"); Episode 12's "formal, static → respectful, understated → same institutional register → peripheral, echoing Episode 7 → grave, formal briefing framing → intimate, unresolved." Each episode's own Camera Direction section must be consulted individually; no general rule may be applied across the whole group.
- **Composition Rules:** No environment-wide composition mandate is confirmed (unlike the Formal Meeting or Neutral Private Meeting Environments' own neutrality rules). Composition must follow each scene's own Camera Notes.
- **Blocking Rules:** Population density varies by dressing (routine patrol to full institutional gathering); no single blocking template applies. Each scene's own Characters Present field governs.
- **Lighting Reference:** FPP-ENV-001's own package; no Lighting Canon contradiction on record for this environment.
- **Transition Rules:** Scene-specific; several episodes (7, 12) confirm hard-cut tonal breaks ("a hard cut, not a swell," Episode 8) as a deliberate, recurring device — this pattern itself is reusable across the group, though individual transition instructions remain scene-specific.
- **Continuity Requirements:** Each character's own Approved Character Production Package (Phase 6B) governs their appearance; no environment-specific Permanent Rule exists for Ward Station Seven.
- **Reuse Opportunities:** Highest in the production by scene count (49), but lowest in template reusability — flagged as requiring the most scene-by-scene storyboard labor of any group, not the least, despite its highest priority ranking.

- **Authority:** Direct scene text from Episodes 22, 27, 34, 35, 36, read during Phase 6C.8/6C.9/6E.1 research; the governing Environment Packages for each institution involved (FPP-ENV-001, FPP-ENV-006, FPP-ENV-008, ENV-013, ENV-014, FPP-ENV-003, FPP-ENV-004, as applicable per episode).
