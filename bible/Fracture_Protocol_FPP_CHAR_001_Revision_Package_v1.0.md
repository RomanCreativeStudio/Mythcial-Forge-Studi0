## 3. Prompt Change Determination

**The Locked Production Prompt is unchanged. No contradiction exists between the prompt and canon.**

Every Required Correction above (RC-1 texture, RC-2 collar, RC-3 invented brand/insignia) concerns an element the Locked Production Prompt never specified in the first place — the prompt's own text ("dark techwear outfit with subtle cyan accents") is silent on surface finish, collar shape, and branding/signage, exactly as the Concept Art Production Workflow Authorization anticipated when it required that "any element the templates don't cover... is flagged, not improvised into the prompt." The violations found originated in ungoverned generation choices made in the space the prompt deliberately left open, not in the prompt's own wording. Editing the prompt to add explicit "matte," "non-decorative collar," or "no logos/text/signage" language is available as a future option but is not required to resolve the contradiction — the External Revision Brief below supplies that guidance separately, outside the canon-locked prompt text itself, consistent with the same separation already used for every other unLocked costume/canon detail in this workflow.

## 4. External Revision Brief — For the Next Concept Art Generation

**Locked Production Prompt (verbatim, unmodified):**

```
Late teen to early adult male protagonist named Kael (17–20), semi-realistic anime
cinematic style, futuristic dystopian megacity environment, dark techwear outfit
with subtle cyan accents, glowing icy-blue cyan eyes, emotional expression focus,
cinematic lighting, high detail face, shallow depth of field, moody atmosphere,
sci-fi identity theme, soft stable eye glow, calm expression, gentle lighting
```

**Corrections required on this attempt (must be satisfied):**
- Matte, non-reflective jacket surface — no gloss, no wet-look sheen.
- Plain, practical, field-functional collar — no decorative/sculptural shaping.
- No text, logos, brand names, signage, or emblem/insignia anywhere in the image or its background — including no "VEYR," no "VEX," no chest patch or rank marker of any kind.

**Improvements to favor, if achievable without conflicting with the above (not mandatory):**
- Clearly icy-cyan, visibly glowing eyes rather than an ordinary blue eye render.
- Visible minor weathering/wear rather than a pristine, flawless finish.
- Practical, low-maintenance hair styling rather than elaborate volume/tousling.
- Outfit cyan accents kept visually secondary in number and prominence to the eye-glow.

**Unchanged from the External Production Package (restated for completeness, not re-derived):** output specifications (4000×4000px, sRGB, finished raster master, native-resolution PNG export); naming convention (`FPP-CHAR-001_Kael_Primary_Outfit_Concept_Art_Calm_v1.0...`); folder destination (`series/01-the-fracture-protocol/concept-art/characters/`); the delivery-method question remains open per the prior directive and is not resolved by this package.
