### Re-Verification Against Full Source Set

Master System Prompt and Production Bible confirmed silent. Phase 4B Episodes 15 and 22 checked directly and independently confirm both the original "no single physical site" finding and — new to this reconciliation pass — a concrete production-design answer:

- **Episode 15's** own Phase 4B Required Environments field reads: "Ward Station Seven, in intelligence/analysis and formal briefing dressings — reused from the season's existing asset base; no new location category." Episode 15 never generates a distinct Ascendant Network environment at any production stage — confirming the original correction (Episode 15 removed from the physical-appearance range).
- **Episode 22's** own Phase 4B Scene 3 ("What the Doctrine Is Approaching" — the scene the final screenplay's Location List identifies as the Ascendant Network's sole physical appearance) is described only as "an institutional or Doctrine-adjacent space, **consistent with Episode 15's world-scale treatment**," with Visual Requirements stating explicitly: "**Same environment category established for Ascendant Network content since Episode 15**; no new location or iconography beyond what's already Locked."

Read together, these two findings resolve the production-design question this environment was originally flagged for: Episode 22's "Ascendant Network world-scale environment" is not a new or distinct physical set — it is **the same environment category as Episode 15's Network-related content**, and Episode 15's own content is explicitly Ward Station Seven, redressed for intelligence/analysis and formal briefing. The Network's own physical space is never depicted anywhere in the production; every scene "about" the Network is staged as Ward Station Seven's institution examining evidence and intelligence regarding it. This is a genuine, evidence-based production answer, not an invented one — it is derived directly from both episodes' own Phase 4B Required Environments fields, not from inference.

Recurring Episodes confirmed final: **22 only**, for physical-appearance purposes; Episode 15 retained solely as the Faction Bible citation source and the origin of the "Ward Station Seven, redressed" production pattern this environment reuses. No further episode-range correction required.
