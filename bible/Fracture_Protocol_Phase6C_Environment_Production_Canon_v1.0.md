# THE FRACTURE PROTOCOL — PHASE 6C: ENVIRONMENT PRODUCTION CANON

**Classification:** Internal — New Locked Production Canon Document (**Compiled — Pending Founder Review**)
**Status:** Compiled 2026-07-15 per "Founder Directive — Phase 6C Environment Production Canon (v1.0)." This document establishes the permanent production authority governing every location appearing throughout The Fracture Protocol. This is a production-phase document — it generates no new story, rewrites no screenplay, and invents no canon. Every environment is derived exclusively from Approved Screenplays, Approved Production Packages, the World Bible, the Art Bible, the Production Bible, and Locked Canon.
**Absolute authority:** subordinate to Master System Prompt → Locked Canon (World Bible, Character Bible, Faction Bible, Phase 2 series) → Production Bible → Approved Screenplays (Phase 5B, Locked under Phase 5B.5) → Phase 6.0 → Phase 6A → Phase 6A.5 → Phase 6B (all sub-phases: Character/Guardian/Human/Costume Visual Canon). ## 1. Purpose

Character Production Authority is now complete (Narrative, Visual, and Costume Authority for all four active principal characters, per Phase 6B/6B.1/6B.2/6B.3). ## 3. Environment Categories

Every environment shall be classified using one or more of the following categories, as applicable — a location may carry more than one (e.g., Ward Station Seven is both Primary Location and Institutional):

Primary Location · Secondary Location · Recurring · One-time · Civilian · Military · Government · Historical · Alien · Restricted · Training · Combat · Transit · Industrial · Medical · Unknown.

No new category is invented beyond this list without a future Founder directive; if an environment does not cleanly fit an existing category, that tension is flagged in its package rather than forcing a fit.

## 4. Environment Standards

Every environment shall define ten identities, each traceable to a cited source:

**Visual Identity · Architectural Identity · Lighting Identity · Material Identity · Scale Identity · Movement Identity · Sound Identity · Color Identity · Camera Identity · Environmental Language.**

**Governing Locked source for these ten identities, cited once here rather than per-package:** `mythic-forge-art-bible/environment-design-rules.md` (Core Requirement: every environment must visually answer "which layer of the city" within roughly two seconds, using palette, architecture, and silhouette alone) and its Layer Visual Logic table:

| Layer | Environment Visual Logic (Locked) |
|---|---|
| Upper Grid | Sterile, minimal, symmetrical, white-dominant — order visible in the architecture itself; emotionally empty by design |
| Mid Zone | Regulated neon-adjacent signage (Authority-sanctioned, never chaotic), dense civilian housing, surveillance infrastructure visible but normalized |
| Lower Sector | Ward Station Seven's home layer — defensive, austere, minimal ornamentation, visible wear and improvised repair; Breach-adjacent zones show environmental distortion |
| Unknown Layer | Never fully rendered on-screen in detail — glimpsed only at the edges, defined by absence and static distortion rather than concrete geography |

**Additional Locked cross-references governing every environment's Material Identity, Color Identity, and Environmental Effects:**
- `mythic-forge-art-bible/materials-and-textures.md` — Surface Rules (concrete/composite always weathered; tech-fabric wear scales with zone/role; metal/alloy always shows forged/machined imperfection; glass/display wear scales with zone); the Root Artifact Exception (the *only* permitted "too-perfect" material treatment, reserved exclusively for founding-era Root Artifact sites); the Imperfection Requirement (every hero location requires at least one visible wear detail, except explicitly official Authority objects where uniformity is itself the intended statement).
- `mythic-forge-art-bible/global-consistency-rules.md` — the megacity's three-color system (black/charcoal, cyan/icy-blue, white) is permanent and universal; no environment introduces a competing palette; the Root Artifact Exception is the only realism exception anywhere; no magic exists — all system effects read as interference, corruption, or perception/emotional instability.
- `mythic-forge-art-bible/system-interference-visual-rules.md` — governs any Cipher-work/Fragment/Breach visual phenomena occurring within an environment (Environmental Effects field): cyan/icy-blue Cipher-glow only, effects obey physical falloff/shadow/reflection exactly like practical light, intensity scales with the tier of Signal activity present, and environmental Signal residue (faint cyan-tinted haze, static, glitch-texture) is permitted at sites of recent Cipher-work or a recent Breach.

Every environment package must list: First Appearance · Final Appearance · Recurring Episodes · Scene References · Speaking Character Interaction · Major Story Function. ## 6. Dependency Validation

Every environment package must identify what depends on it and what it depends on: Characters using it · Props · Technology · Vehicles · Weapons · VFX · SFX · Music · Animation · Lighting · Camera · Reusable Assets. Per Phase 6A's Master Asset Backlog (already Locked/Approved), zero new props, weapons, vehicles, technology, or VFX assets are required anywhere across all 36 screenplays — this finding is carried forward and re-confirmed, not re-derived, in each environment's Dependency Validation unless a specific package's own research finds a contradiction (which would be flagged as a Canon Contradiction stop condition, not silently resolved).

## 7. Production Order — Methodology

Environments are built in dependency order — highest dependency first — never alphabetical, per this directive's explicit Step 2 instruction. "Dependency" here is read consistently with how Phase 6A's own Asset Priority Matrix already established character priority: highest episode-reuse and highest narrative-centrality first. Phase 6A's own Master Asset Backlog already performed exactly this ranking for all identified environments (`bible/Fracture_Protocol_Phase6A_Master_Production_Roadmap_v1.0.md`, "Environments" section and Priority Matrix) — this document adopts that existing, Approved ranking as its Production Priority List rather than re-deriving a new one, since re-deriving would risk silently contradicting an already-Locked prioritization.

**Production Priority List (adopted from Phase 6A, Asset Registry FPP-ENV-001 through 010):**

|---|---|---|---|
| 1 | Ward Station Seven | 1 (highest) | Season One recurring (1–12), 22, 23, 27 |

**Deferred, not fabricated — the remaining ~18 environments (FPP-ENV-011...n):** Phase 6A's own Master Asset Backlog explicitly declined to itemize these individually, "to avoid inventing IDs for locations not yet needed" — each is a single/low-frequency Season One or Arc Two location (1–2 episodes each) enumerable only from its specific screenplay's own Location List when production reaches that episode. This document honors that same discipline: it does not invent 18 environment names or IDs to fill a quota. These remain a tracked, explicitly-flagged production gap (see Section 9, Environment Priority Report, in the companion Final Reports document) rather than a silently-dropped requirement.
