This is a cutting/editing discipline, not a rendered visual effect, and is recorded here for completeness rather than as a new VFX asset. |
| **Atmospheric Effects** | **Confirmed zero.** Direct search for fog, mist, dust, haze, rain, snow, smoke, steam, smog, and particulate matter across all 36 screenplays returns no results. This is a genuine, confirmed absence — not an unchecked gap. |
| **Lighting-Driven Effects** | **No independent asset beyond the two already listed.** The Locked Emotional Lighting Modes system (Grounded/Charged/Wounded, `lighting-system.md`) is a cinematography/lighting discipline governed by Phase 6C, not itself a VFX asset. The only genuinely lighting-driven visual effects in the production are Kael's eye-glow (Character Visual Effects, above) and the Breach-adjacent disturbance effect's own confirmed "lighting shift governed jointly with `system-interference-visual-rules.md`" (Environmental Visual Effects, above) — both already counted, not double-logged here. |
| **Interface / Display Effects** | **Confirmed zero**, reconfirming Phase 6D.1's and Phase 6D.1.5's own findings: no terminal, console, display, monitor, or screen (as a physical object) exists anywhere in the 36 screenplays. There is consequently no interface-driven visual effect to inventory. |
| **Reusable Effect Libraries** | **Two confirmed:** (1) Kael's eye-glow 4-state library (Calm/Conflict/Activation/Breakdown), reusable across all 36 episodes; (2) the Breach-adjacent disturbance effect's own 3-instance escalation template (Episodes 1, 2, 9), which functions as a scalable effect library in miniature — each instance is a confirmed variant of the same underlying effect, not an independent design. |

**Total confirmed visual effects in the entire 36-episode production: 2** (Kael's eye-glow; the Breach-adjacent disturbance lineage). This is not an incomplete inventory — it is the direct, exhaustive, category-by-category result of searching all 36 screenplays, reconfirming with maximum specificity the production's own repeatedly-stated "zero new VFX" finding, now broken out honestly across all 7 requested categories rather than left as a single blanket claim.
