# THE FRACTURE PROTOCOL — CANON REGISTRY
## Organizations, Institutions, Doctrines, and Governing Principles

**Classification:** Internal — Canon Index
**Status:** Established 2026-07-10, per Founder Directive ("Canon Consolidation — Phase 1A & Phase 1B," Repository Task 4: "Update the Canon Registry with every finalized organization, doctrine, institution, and governing principle introduced in this directive").
**Purpose:** A single index of every named organization, institution, doctrine, and governing/founding principle across all of *The Fracture Protocol*'s canon — not a new source of truth. Each entry points to the actual Locked document and section that defines it; this registry never redefines anything itself. If this index and a source document ever disagree, the source document wins and this registry is corrected.
**Distinct from:** `documentation/Asset_Registry.md`, which tracks Mythic Forge Studios *brand assets* (logos, banners, exports) — a completely different domain (studio/production assets vs. story canon). No overlap in scope.
**Governed by:** `bible/Fracture_Protocol_Master_System_Prompt_v1.2.md` Section 12 (Canon Governance System) — an entry here reflects Locked or Approved canon only; nothing from `bible/Fracture_Protocol_Proposal_Vault_v1.0.md` (Proposed, not yet canon) is listed until it's promoted.
