## How to use this document

This is the archive for future ideas — a parking lot, not a pipeline. An idea sitting here has no bearing on continuity, no matter how long it sits here or how well-developed it becomes. It only leaves this document and enters canon through the Canon Update Workflow (Master System Prompt Section 12, Rule 6), which requires explicit creator approval first.

Every entry uses this exact format (Rule 5):

```
### [Entry Title]

**Status:** Proposed — Not Canon
**Date Logged:** YYYY-MM-DD
**Purpose:** Why this idea exists — what problem or opportunity it addresses.
**Impact:** Which documents would change if this were approved (name them specifically).
**Recommendation:** Whether this should remain optional, be prioritized, or be reconsidered — framed as a recommendation, never as a decision.
```

Entries are never deleted once logged — a rejected or shelved proposal stays here, marked accordingly, as part of the project's decision record.

## Current Entries

### A Hidden Organization Secretly Controlling the Authority System

**Status:** Proposed — Not Canon
**Date Logged:** 2026-07-06
**Purpose:** Requested as a new faction that secretly controls the Authority System — presumably to add a deeper "who really holds power" layer beneath the visible Ward Division / Authority / Reassembly structure, and to seed a higher-tier antagonist force for later seasons.
**Impact:** This would touch more of the locked framework than a typical new-faction proposal:
- **Master System Prompt, System Rule 2 (Locked):** "Authority is always active. The system cannot be removed, destroyed, or ignored." A faction literally *controlling* Authority risks contradicting this outright — Authority would need to remain autonomous and permanent regardless of this group's existence. At most, a compatible version would have the group *influencing specific decisions or personnel from within* (e.g., manipulating individual Division Directors or Authority Central inspectors), never controlling the system itself.
- **World Bible Section 4 (Authority System) and Section 9 (the Reassembly):** real risk of redundancy. The Reassembly already occupies the "secret network with an agenda about the system's true nature" narrative space, and its central ambiguity — would reassembling Fragments liberate the city or produce a more total form of control? — is Locked scaffolding not to be resolved early. A second, similarly-shaped secret organization needs a clearly distinct goal, method, and relationship to Authority, or it dilutes rather than deepens that existing mystery.
- **World Bible Section 2 (The Fracture, founding event — deliberately unresolved):** this is exactly the kind of idea that could either enrich or prematurely resolve "what caused the Fracture" and "who/what is in the Unknown Layer." High risk of answering a question the franchise is explicitly built to keep open for now.
- Would require a new World Bible section, likely Series Bible Running Mysteries updates, and possibly Character Creation Rule adjustments if it introduces named members.
**Recommendation:** Hold, don't implement now. If pursued, it should (a) be framed as *influence from within*, never *control of*, Authority, to stay compatible with System Rule 2; (b) be explicitly differentiated from the Reassembly's goals and methods so the two don't collapse into the same idea; and (c) be reserved for a later season (Season 3+, where Series Bible Section 12 already plans "the Reassembly as an ecosystem of cells, not a single enemy" — this could slot in there rather than as a standalone new faction) rather than introduced immediately. Recommend the creator clarify intent (is this meant to replace/reframe the Reassembly, sit above it, or be something else entirely) before any drafting begins.

### Currency & Economic System

**Status:** Proposed — Not Canon
**Date Logged:** 2026-07-06
**Purpose:** No economic system exists anywhere in canon, despite the Salvage Line explicitly "dealing in" Root Artifacts, off-record identity data, and Fragment salvage — trade implies some medium of exchange, and a production-ready world needs one for texture (market scenes, bribes, black-market pricing, Ward Division wages, etc.).
**Impact:** New World Bible section (proposed Section 17). No Locked rule conflict — this is a pure gap-fill, not a change to anything existing. Series Bible would only gain optional flavor detail, no plot changes required.
**Recommendation:** Low-risk, genuinely useful, safe to prioritize whenever convenient. Suggested direction (not yet canon): an Authority-issued digital credit tied directly to registered identity — thematically clean, since it means economic standing is literally part of the same "Identity = Data" system (System Rule 1), giving Authority a quiet lever (freezing or adjusting someone's credit) it doesn't need to justify. The Salvage Line would deal mostly in barter and untraceable off-record credit specifically because it isn't tied to registered identity.

### Continuum Recovery Group (new faction)

**Status:** Proposed — Not Canon
**Date Logged:** 2026-07-06
**Purpose:** Requested as a new faction. Every existing organization occupies a distinct lane — Authority (state governance), Ward Division (state containment institution), the Reassembly (ideological resistance), the Salvage Line (illegal, pragmatic black market) — but nothing represents *legal* commercial interest. A licensed corporate contractor fills that gap without duplicating any existing faction's role or ideology, and introduces a genuinely new thematic axis: corporate profit motive operating alongside, and sometimes against, state and ideological interests.
**Concept sketch:**
- **Continuum Recovery Group** holds an exclusive Authority contract to recover, catalog, and "process" Root Artifacts and Breach-site salvage on Authority's behalf — the legal, sanctioned counterpart to what the Salvage Line does illegally.
- Not evil, not heroic: profit-driven. Continuum's incentive is to keep Breach recovery contracts profitable and renewable, which means it has a quiet interest in Breaches continuing to happen at a manageable rate — not too many (bad PR, contract risk), not too few (no work). This is a distinct moral shape from any existing faction: Authority wants control, Ward Division wants genuine containment, the Reassembly wants change, the Salvage Line wants to stay unowned. Continuum wants steady, renewable business.
- Plausible friction points: Continuum quietly redacting or burying inconvenient Root Artifact findings that would embarrass Authority or complicate a contract renewal; competing with the Salvage Line over the same salvage sites (legal vs. illegal claim to the same recovered material); a Continuum technician being a far more mundane, bureaucratic obstacle for Kael than any ideological antagonist.
**Impact:** New World Bible section (would sit near Section 16, the Salvage Line, for easy contrast). Would need a Character Creation Rules note if named Continuum personnel are introduced. No Locked rule conflict — doesn't touch Authority's core immutability, doesn't compete with the Reassembly's central mystery, doesn't require resolving anything currently unresolved.
**Recommendation:** Approve-ready as concepts go — this is the cleanest of the batch precisely because it doesn't overlap with anything that already exists. If approved, recommend introducing it in Season Two or later (matching the Salvage Line/Coda timeline) rather than retrofitting it into Season One's locked outline.

### United Solar System Nations (USCN), Light Order, and Night Haven

**Status:** **Split 2026-07-09.** Light Order and Night Haven (as named factions and as the stated Core Conflict) are now **Approved Canon — Locked**, compiled into `bible/Fracture_Protocol_Phase1A_Production_Bible_v1.0.md` per an explicit follow-up Founder directive ("Production Bible Compilation — Phase 1A") that confirmed Phase 1A scope specifically and stated "No additional Founder clarification is required unless a genuine contradiction is discovered." The USCN interplanetary government structure (Chancellor, Assembly, Supreme Court, Solar Peace Corps, planetary governments — "Phase 1B, Universe Framework") remains **Proposed — Not Canon** below: that follow-up directive explicitly scoped its compilation instruction to Phase 1A only, leaving Phase 1B's single-megacity-vs-interplanetary-civilization conflict (still unresolved, see below) untouched. Original entry preserved for its still-relevant Phase 1B analysis.
**Date Logged:** 2026-07-09
**Purpose:** Submitted as a "Founder Directive — Canon Update," framed as a terminology fix ("replace UNSC with USCN") plus a new interplanetary governing body (USCN) and two new political/ideological factions (Light Order, Night Haven).
**Impact — flagged by Drift Detection (Master System Prompt Section 12, Rule 3) on multiple independent grounds, not implemented:**
- **"Replace UNSC with USCN" has nothing to act on.** A full-repository search found zero existing references to "UNSC" anywhere in this project. There is no placeholder to replace.
- **This is not a terminology change — it conflicts with Locked World Structure.** World Bible Section 1 (Universe Overview, Locked) states, verbatim: *"The Fracture Protocol is a single, controlled megacity — not a scattered multiverse, not seven kingdoms, one place."* The submitted USCN concept describes an interplanetary alliance spanning Earth, Mars, the Moon, and other member worlds, each with its own sovereign government. That is a different scope and structure of universe than the one Locked in canon, not a rename within it. Master System Prompt Rule 4 (Locked Categories) lists "World structure" and "Major institutions" as categories that may never change automatically.
- **Light Order and Night Haven have no existing analog.** The only organizations currently in canon are Authority (World Bible Section 4), Ward Division (Section 6), the Reassembly (Section 9), the Salvage Line (Section 16), and the proposed-but-undecided Continuum Recovery Group (above). None operate beyond the single megacity; nothing currently in canon resembles a Solar-System-spanning ideological rivalry playing out across planetary governments, militaries, and industry.
- **This is classified a Major Canon Update** per Master System Prompt Section 13 (new organizations, world structure changes, new core terminology are all independently listed triggers) — which requires a Change Impact Report (this entry) and, because it affects World Structure specifically, **one final confirmation from the Founder before any document is updated, even though "Founder Approval: Status: Approved Canon" was already stated in the directive** (Section 13: "If the requested change affects multiple core systems... Claude must request one final confirmation before making the update, even if an Override Command was already given").
- **Documents that would change if approved:** World Bible Section 1 (Universe Overview) and Section 3 (Megacity Structure) would need to be rewritten, not extended, since the current text explicitly rules out a multi-world setting; Master System Prompt Section 3 (Universe Identity) would need review for consistency; Series Bible would need a pass for any assumed single-city geography; Production Bible and Art Bible would need review for any single-city visual/production assumptions built on the current scope.
- **Documents that would NOT change:** Brand Bible, Studio OS, YouTube Brand Kit, and all BRA-0001/BRA-0001A brand-asset governance — this is a story-canon question, entirely outside that system.
- **Reversibility:** technically reversible via git history, but in practice this would be a foundational retcon of the established setting, not a minor addition — the kind of change this project's own Canon Governance System was specifically built to slow down and make deliberate, not fast-track.
**Recommendation:** Hold as Proposed pending the Founder's explicit confirmation of intent, specifically: is USCN/Light Order/Night Haven meant to (a) replace the single-megacity setting with an interplanetary one — a genuine, large-scope retcon, (b) exist as a separate, future Mythic Forge Studios property distinct from The Fracture Protocol, or (c) something narrower not yet captured here (e.g., a frame/context that sits *around* the megacity without contradicting its self-contained description)? The single-megacity framing is quoted directly above so the conflict is concrete, not asserted.
