## Step 1 — Prompt Assembly: STOPPED, Contradiction Found

Assembling the production prompt required combining `prompt-library.md`'s Locked Kael Base Prompt Template with Phase 6B.3's Locked Costume Canon (Concept Art Priority 1: Primary Outfit). Direct comparison surfaced a **genuine contradiction between two Locked Canon sources**, not a misreading:

- **`prompt-library.md`'s Kael Base Prompt Template** (Master System Prompt Section 9, canon-locked verbatim): *"...futuristic dystopian megacity environment, **dark techwear outfit with subtle cyan accents**, glowing icy-blue cyan eyes..."*
- **`Fracture_Protocol_Phase6B3_Costume_Wardrobe_Visual_Canon_v1.0.md`, Section 2, Color Distribution field** (Locked): *"Muted neutrals dominate; **cyan/icy-blue appears nowhere on the costume itself — reserved exclusively to his eyes** (Phase 6B.2 Color Philosophy, Locked)."*

These directly conflict on a single, unambiguous point: whether cyan appears anywhere on Kael's Primary Outfit. The Base Prompt Template says yes ("subtle cyan accents" on the outfit); the Costume Canon says no ("appears nowhere on the costume itself"), and independently, Kael's own Character Production Package repeats this as a **Do Not Do** rule: "never use cyan decoratively anywhere but his eyes."

Per Phase 6K.0 §7 (Production Conflict Resolution): *"A contradiction between two Locked Canon sources... production on that specific piece of concept art stops, and the conflict is flagged for Founder decision... No conflict of this kind may be silently resolved."* I have no authority to unilaterally edit the canon-locked-verbatim prompt template, and no authority to override the Costume Canon's explicit Color Distribution rule. **Production stops here.**

**Secondary, lower-confidence item, flagged for completeness, not treated as a second stop condition:** the Base Prompt Template states Kael's age as "17–20." No Locked source in the Character Bible or his Character Production Package's own Physical Production Profile confirms or contradicts this — age is simply absent from every source checked. This is an unconfirmed gap, not a direct contradiction like the cyan issue, but is noted since it bears on the same prompt.
