## FPP-ANIM-001 — Kael's Core Library + Eye-glow Emotion Modifier System

- **Authority:** Kael's Character Production Package (Phase 6B.2 update, Sections 3, 5–7); Phase 6B.1's cross-reference to the eye-glow Signal-Sensitivity system.
- **Governing Sources:** Kael's Character Package (10/10 Expressions, 9/9 Poses, all confirmed required); FPP-SB-001 through FPP-SB-006, FPP-SB-008 through FPP-SB-010, FPP-SB-016 (present in nearly every sequence group); all 36 screenplays' own Action/Performance Notes involving Kael.
- **Character Motion:** Economical, controlled, disciplined movement; shoulder tension as burden; sharpens during Activation (Phase 6B.2 Movement Style and Posture rules, cited directly in his Pose Library update).
- **Facial Performance:** Must apply the eye-glow Emotion Modifier consistent with in-scene state (Calm/Conflict/Activation/Breakdown) for every one of the 10 fixed Expressions — expression and eye-glow state are never designed independently, per his own package's explicit instruction. Must support intra-scene transitions (e.g., Calm → Conflict → Activation within one confrontation, as his package's own example specifies).
- **Body Mechanics:** Confirmed character-state variants must be reflected precisely, not generically: Episode 2's strain/injury state (introduced Scene 4, peaking Scene 5); Episode 7's rank-advancement marker (an update to his existing asset, not a new design); Episode 12's Senior Ward marker (same update pattern).
- **Camera Interaction:** No single confirmed camera template exists across his full appearance range (per FPP-SB-001's own disclosed gap); motion must be built to accommodate each scene's own specific Camera Notes rather than one general blocking assumption.
- **Timing:** Facial/eye-glow transitions must be capable of occurring within a single scene, per his own package's explicit intra-scene example — this is a hard constraint on rig and animation-system design, not a stylistic preference.
- **Continuity:** His eye-glow state must track Signal-Sensitivity consistently across every appearance; no scene may show an eye-glow state inconsistent with its own confirmed emotional/narrative beat without Founder flag.
- **Reuse Rules:** Highest-reuse asset in the production (36 episodes); the core library and eye-glow system are built once and reused throughout, with only the three confirmed character-state variants (Episodes 2, 7, 12) requiring distinct treatment.
- **Production Status:** Required — Not Yet Produced. No facial bone-structure or muscle-shape reference exists (flagged in Phase 6F.1); this remains the single largest open item blocking actual rig production.
