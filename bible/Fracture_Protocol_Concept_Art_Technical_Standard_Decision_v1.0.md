## 1. Resolution Standard

**Decision: Category-specific standards, not a single universal value.**

| Category | Master Canvas | Basis |
|---|---|---|
| Character | **4000 × 4000 px** | Square canvas sized to accommodate Phase 6A.5's own required Character deliverable set in one working file — full-body Turnaround plus Expression/Pose grid insets — without forcing a wide or portrait-only crop that would compress facial detail below the Locked "high-detail facial focus" register. |
| Environment | **5120 × 2880 px** | Wide-format canvas for Phase 6A.5's own Environment Master View/Layout deliverable, scaled up from the one existing Locked wide-canvas precedent in this production (the Brand Asset line's 2560×1440 YouTube banner) to accommodate a full environment master view at working resolution — same aspect-ratio family, not the same asset or a literal reuse of that figure. |
| Prop | **2048 × 2048 px** | Square canvas sized for Phase 6A.5's own Prop Orthographic Views/Scale/Material Notes deliverable — a smaller working canvas than Character or Environment, appropriate to a single small object (FPP-TECH-001, currently the only confirmed Prop). |
| VFX | **2048 × 2048 px** (provisional) | Matches the Prop baseline pending resolution of the separate, still-open gap identified in the Art Bible Concept Art Standard Expansion: Phase 6A.5 defines no "VFX Standards" deliverable category at all. This figure is not derived from any VFX-specific citation and should be revisited once that category is properly defined. |

**Justification for category-specific over universal:** Phase 6A.5's own Character, Environment, and Prop Standards sections each define structurally different deliverable shapes (full-body multi-pose vs. wide master view vs. small multi-view orthographic sheet) — a single universal resolution would either under-serve the wide Environment master view or waste canvas on the smaller Prop/VFX deliverables. This follows the same "one master, scaled per context" principle Phase 6A.5 itself already authorized extending from the Brand Asset Production Guide, applied at the category level rather than forcing one dimension across incompatible deliverable shapes.

**Export scaling:** each category's master canvas is scaled via the already-Approved raster export convention (PNG export set, per the Concept Art Technical Standard Authorization's own File Format Standard) — no new export philosophy is introduced.

## 2. Color-Management Standard

**Decision: sRGB, applied universally across all four Concept Art categories, and intended to remain the working standard through Final Edit and Master Release.**

**Justification:**
- **Compatible with Art Bible visual authority, not competing with it.** Color space is a technical delivery encoding; it does not touch, reinterpret, or override the Locked three-color meaning-system (`color-language.md`: black/charcoal = identity, cyan/icy-blue = anomaly, white = authority). sRGB governs how those already-Locked hues are encoded for digital display, not what they mean.
- **Consistent with the studio's own confirmed distribution strategy.** This production is YouTube-first (Studio OS's own established digital-distribution direction) — sRGB is the standard, near-universal color space for web/streaming delivery, and using anything else would require a conversion step with no Locked justification.
- **Already the de facto standard in this repository without conflict.** Every prior Brand Asset PNG/SVG deliverable in this production was produced and delivered without any color-space-specific complication or flag — sRGB is the practical default those assets already operated under, made explicit here rather than left implicit.
- **Uniform across categories, unlike resolution.** Color space is a pipeline-consistency requirement, not asset-type-dependent — no compatibility tension exists across Character/Environment/Prop/VFX for this specific standard, consistent with the compatibility finding already made in the Art Bible Concept Art Standard Expansion.
- **Forward-compatible with future production stages.** sRGB remains the standard delivery space through Animation, Final Edit, and Master Release (Production Authority Hierarchy levels 10, 12, 13) — this decision does not need revisiting when those stages eventually begin.

## Remaining Decisions

1. **VFX's own Phase 6A.5 deliverable-category definition remains undefined** (no "VFX Standards" section exists) — the VFX resolution figure above is a provisional placeholder, not a citation-backed final value, and should be revisited once that gap is separately resolved.
2. **These numeric values are new administrative decisions, not derived from prior Locked citation** — if the Founder wants them promoted to full Locked Art Bible status (rather than remaining at the Concept Art governance layer this document occupies), a separate Art Bible amendment directive would be required.
3. **FPP-CHAR-001's Exploration asset is not approved, re-evaluated, or altered by this decision.** It happens to already comply with the File Format Standard (SVG) but was produced before these resolution/color-management values existed and has not been checked against them — no such check is performed here.
