# THE FRACTURE PROTOCOL — PHASE 6H.0: VISUAL EFFECTS PRODUCTION GOVERNANCE

**Classification:** Internal — Governance Document (**Approved**)
**Status:** Compiled 2026-07-15 per "Founder Directive — Phase 6H.0 Visual Effects Production Governance (v1.0)." Continues directly from Phase 6G.2. This document creates no visual effect, modifies no canon, and rewrites no screenplay. It establishes only the new governance Phase 6H (Visual Effects Production) requires — it does not restate the Environment (Phase 6C), Prop & Technology (Phase 6D.0), Storyboard (Phase 6E.0), Animation (Phase 6F.0), or Audio (Phase 6G.0) governance already Locked; those remain in force, unmodified, and are cited by reference only.
**Absolute authority:** subordinate to Master System Prompt → Locked Canon (World Bible, Character Bible, Faction Bible) → Production Bible → Approved Screenplays → Art Bible (`system-interference-visual-rules.md`, `color-language.md`, `lighting-system.md`) → Phase 6B Character Production line → Phase 6C Environment Production Canon and its full reconciliation lineage → Phase 6D.0/6D.1/6D.1.5 Prop & Technology Production → Phase 6E.0/6E.1/6E.2 Storyboard Production → Phase 6F.0/6F.1/6F.2 Animation Production → Phase 6G.0/6G.1/6G.2 Audio Production → **Phase 6H.0 Visual Effects Production Governance**.

---

## 1. Purpose

Phase 6H exists to govern the production of visual effects — system-interference phenomena (Cipher-work, Fragment apparitions, Breach-adjacent distortion), Kael's eye-glow Emotion Modifier, and any other confirmed effect already on record across the screenplay corpus, Character Production Packages, and Environment Production Packages. Phase 6H.0 establishes only the rules that govern this work. It authorizes no visual effect itself.

---

## 2. VFX Authority

A visual effect is authorized only by:
1. The specific screenplay scene's own Required Visual Effects field, cited directly — the overwhelming majority of confirmed scenes across all 36 screenplays explicitly state "None," and this confirmed absence is binding, not a gap to fill.
2. A character's own Approved Character Production Package, where a confirmed character-level visual effect exists (Kael's eye-glow Emotion Modifier system, Phase 6B, Sections 3 and 5, cross-referenced into FPP-ANIM-001).
3. An environment's own Approved Environment Production Package, where a confirmed Environmental Effects field is populated (e.g., ENV-011's Breach-adjacent disturbance effect lineage, Episodes 1, 2, 9).

A visual effect with no citable source in one of these three categories does not exist for production purposes — it must be flagged as missing, never invented. Per this production's own repeatedly reconfirmed finding (Phase 6A through Phase 6D.1), the default state of nearly every scene, environment, and character in this production is **zero visual effects** — this is a confirmed fact, not an unexamined gap, and VFX production must treat "None" as a governing instruction, not an invitation to add spectacle.

---

## 3. Effects Authority

Where a visual effect is confirmed, its specific visual character is governed by:
- `system-interference-visual-rules.md`'s own Locked rules: system-effect light obeys physical falloff, occlusion, and shadow-casting exactly like practical light — never a flat, unshadowed glow; intensity and steadiness scale with the user's skill and cost being paid (World Bible Section 7); Fragment apparitions are translucent, light-distorting presences, never solid character models.
- The Locked permanent three-color system (`color-language.md`, `global-consistency-rules.md`): cyan/icy-blue is reserved exclusively for Fracture-anomaly phenomena, Kael's eye-glow, Cipher-work, and Breach residue — never decorative, never assigned to any other asset.
- Each confirmed effect's own specific citation: Kael's eye-glow must track his Signal-Sensitivity state (Calm/Conflict/Activation/Breakdown) exactly as FPP-ANIM-001 already requires; the Breach-adjacent disturbance effect must escalate consistently with its own confirmed lineage (Episode 1 → Episode 2 "scaled" → Episode 9 "further-scaled"), never redesigned independently at each appearance.

No effect may be produced with a visual character beyond what its own governing citation supports — a confirmed "disturbance effect" may not be elaborated into a specific mechanism, form, or spectacle-level treatment absent a further citation, consistent with Phase 5A.2's own mystery-protection discipline where it applies (e.g., Mira's Episode 33 mechanism, which remains outside VFX Authority entirely per that Lock).

---

## 4. Compositing Authority

Where a visual effect must be composited against a character or environment plate, compositing decisions are governed by:
- The governing Environment Production Package's own Lighting Rules/Lighting Philosophy field, so that any composited effect respects that environment's own confirmed or Permanent Lighting Canon (e.g., Night Haven's Phase 6C.7 Permanent Lighting Canon governs how any effect composited into a Night Haven scene must integrate with its beat-dependent register).
- The governing Storyboard Production Package's own Camera Language and Composition Rules, so that a composited effect never introduces a visual emphasis or coding the screenplay's own Performance Notes do not support (e.g., an effect may never be composited in a way that codes a character as dominant where a scene's own neutrality mandate forbids it).
- `system-interference-visual-rules.md`'s own physical-integration rule: system-effect light must obey the same falloff/occlusion/shadow-casting as practical light in the shot it is composited into — a flat overlay divorced from the plate's own lighting is prohibited.

---

## 5. Continuity Rule

Every visual effect must remain consistent with:
- Its own prior appearances' confirmed visual lineage (e.g., the Breach-adjacent disturbance effect's own escalating-but-consistent character across Episodes 1, 2, and 9 — each appearance is a variant of the same effect, not an independently designed one).
- The Locked permanent three-color system's reservation of cyan/icy-blue, without exception, across every environment and character it touches.
- The Guardian's own Locked Mystery Protection Rule (Phase 6B.1): the Guardian has no confirmed visual effect of any kind — no glow, no VFX, no lighting distinction — and this absence is itself a Locked, continuity-protected fact that VFX production may never contradict by adding one.

Any apparent inconsistency between a proposed effect and its own governing screenplay, character, or environment package must be flagged for Founder decision under the Production Conflict Rule (Section 7, below), never silently resolved by the VFX team's own judgment.

---

## 6. Effect Revision Rule

Any revision to an Approved visual effect must:
- Reopen the existing effect entry, never overwrite it silently — preserving all prior Founder Approval as historical record, per the reopen-and-append method already established throughout this production.
- Cite the specific new source that justifies the revision (a corrected screenplay, an updated character/environment package, or a new Founder Directive).
- Carry its own new Founder Review, Alignment Audit, and Founder Approval before superseding the prior version.
- Never delete a prior version's record — mark it Superseded, consistent with the standing "nothing disappears without a record" practice.

---

## Version Control

Every VFX production document follows the same versioning discipline standing across this entire production: `v1.0` on first compilation, incremented major versions on Founder-directed content changes, changelog entries preserved in full at every version, and git commit/push performed separately for content-compilation versus Founder-approval steps wherever both occur in the same session.

---

## 7. Production Conflict Rule

If any VFX work finds:
- A contradiction between two Locked Canon sources,
- A contradiction between a screenplay's own Required Visual Effects field and its governing Character or Environment Production Package,
- An effect with no citable source anywhere in VFX, Effects, or Compositing Authority (Sections 2–4), or
- Any indication of repository corruption or a missing Locked authority,

production on that specific effect stops, and the conflict is flagged for Founder decision — exactly as the Lighting Canon rule and every prior Phase 6 Production Conflict Rule already require in their own domains. No conflict of this kind may be silently resolved by VFX-stage inference, convenience, or default. This includes, without exception, any apparent creative need to add an effect the governing sources do not confirm — such a need is always flagged, never self-authorized.

## Amendment — Full Six-Source VFX Authority

*(Appended 2026-07-15 per the reissued "Founder Directive — Phase 6H.0 Visual Effects Production Governance (v1.0)," which explicitly enumerates six authorized derivation sources. Everything above this line is preserved unmodified, per the Effect Revision Rule's own reopen-and-append method.)*

### Finding

The original Section 2 (VFX Authority) cited three sources — Approved Screenplays, Approved Character Production Packages, Approved Environment Production Packages — while Approved Storyboard Packages and Approved Animation Packages appeared only under Section 4 (Compositing Authority), not as primary VFX-authorizing sources in their own right. The reissued directive explicitly requires all six sources (Locked Canon, Approved Screenplays, Approved Character Packages, Approved Environment Packages, Approved Storyboard Packages, Approved Animation Packages) to govern VFX derivation directly. This amendment closes that gap.

### VFX Authority — Amended (supersedes Section 2's source list, all other Section 2 text unchanged)

A visual effect is authorized only by:
1. **Locked Canon** — the World Bible, Character Bible, Faction Bible, and the Art Bible's own system-interference and color-language rules, which bound every effect's permissible visual character before any specific citation is checked.
2. **Approved Screenplays** — the specific scene's own Required Visual Effects field, cited directly (confirmed "None" in the overwhelming majority of scenes, which is binding).
3. **Approved Character Production Packages** — a confirmed character-level visual effect (Kael's eye-glow Emotion Modifier system).
4. **Approved Environment Production Packages** — a confirmed Environmental Effects field (e.g., ENV-011's Breach-adjacent disturbance effect lineage).
5. **Approved Storyboard Production Packages** — where a Storyboard Package's own Composition or Blocking Rules already presuppose an effect's presence within a shot (e.g., a confirmed camera treatment built around an effect's occurrence), that package is itself an authorizing source, not merely a compositing constraint applied after the fact.
6. **Approved Animation Production Packages** — where an Animation Package's own Facial Performance or Body Mechanics fields already confirm an effect-linked requirement (e.g., FPP-ANIM-001's own confirmed eye-glow/facial synchronization requirement), that package is itself an authorizing source for the corresponding effect.

A visual effect with no citable source in any of these six categories does not exist for production purposes — it must be flagged as missing, never invented. This amendment does not change the underlying determination already made under the original three-source reading: no additional effect is newly authorized by broadening the source list, since no Storyboard or Animation Package currently on record introduces an effect requirement beyond what the original three sources already established (Kael's eye-glow, the Breach-adjacent lineage). The amendment closes a citation-structure gap, not a substantive one.

### Flag-Don't-Invent Rule (explicit standalone restatement)

Per the reissued directive's own explicit emphasis, this is restated here as its own standing rule, not left implicit within Section 2 alone: **wherever any of the six authority sources is silent, incomplete, or ambiguous about a visual effect, VFX production must flag that gap explicitly and stop — it must never fill the gap with an invented effect, mechanism, or visual detail, regardless of how minor or seemingly-obvious the addition might appear.** This applies with equal force to every one of the six sources, not only to screenplays.
