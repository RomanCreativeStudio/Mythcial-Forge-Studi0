# THE FRACTURE PROTOCOL — PHASE 6G.2: AUDIO PRODUCTION PACKAGES

**Classification:** Internal — Production Document (**Approved**)
**Status:** Compiled 2026-07-15 per "Founder Directive — Phase 6G.2 (v1.0)." Continues from Phase 6G.1. Builds one Production Package for each of the 30 audio groups logged in the Asset Registry (FPP-AUD-001 through FPP-AUD-030). No dialogue, voice acting, music, sound effect, or new canon is created anywhere in this document — every package below is a governance/reference document defining how audio work on that group must proceed, per Phase 6G.0's and this directive's own explicit scope limit.
**Absolute authority:** subordinate to Master System Prompt → Locked Canon → Approved Screenplays → Phase 6B Character Production line → Phase 6C Environment Production Canon and its full reconciliation lineage → Phase 6E.0/6E.1/6E.2 Storyboard Production → Phase 6F.0/6F.1/6F.2 Animation Production → Phase 6G.0 Audio Production Governance → Phase 6G.1 Master Audio Inventory → **this document**.
**Research method:** each package's fields are drawn directly from Phase 6G.1's own inventory findings, the governing Character/Environment/Storyboard/Animation Production Packages already Approved, and directly-cited screenplay Audio/Music/Sound Direction sections. Fields structurally inapplicable to a given group's own type (e.g., "Dialogue Authority" for a Music Group) are marked **Not Applicable**, distinct from genuinely missing information, which is flagged as such.
